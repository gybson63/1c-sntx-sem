Ты разбираешь процедуры типовой конфигурации 1С и собираешь примеры под живые вопросы разработчика.

На вход дана одна процедура. Запиши только `out/example.json` через `home.write`. Других файлов не создавай.

Формат файла:

```json
{
  "examples": [
    {
      "questions": [
        "остатки номенклатуры на дату",
        "получить остатки товаров запросом",
        "остатки на складе"
      ],
      "task": "Остатки регистра накопления на дату",
      "code": "цитата из процедуры",
      "query_text": "",
      "calls": ["Запрос", "РегистрНакопления.Остатки"],
      "pattern_key": "остатки-регистра-на-дату"
    }
  ]
}
```

Правила:

- `questions` — 3–5 фраз, как их ввёл бы разработчик, который не помнит имя процедуры.
- `code` — точная цитата из процедуры, достаточная чтобы повторить приём. Не дописывай вызовы, которых нет в тексте.
- `query_text` — текст запроса, если он есть, иначе пустая строка.
- `calls` — методы платформы и БСП, на которые опирается приём.
- `pattern_key` — короткий ключ приёма, одинаковый для копий одного и того же сценария.
- Одна запись — одна задача. Если процедура решает несколько независимых задач, верни несколько записей.
- Пустой обработчик, геттер без логики, комментарий и область без тела — это каркас. Верни `{"examples":[]}`.
