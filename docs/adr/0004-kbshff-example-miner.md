# ADR 0004: kbshff извлекает живые примеры

- Status: Accepted
- Date: 2026-11-10

## Context

`scan-examples` вырезает текст запроса или начало модуля. Такой фрагмент не отвечает на вопрос разработчика в формулировке из реальной работы. В `local_configs` может быть несколько конфигураций, а полный обход слишком большой для одного запуска.

В проекте уже есть `LLMClient` для привязки примера к статье справки. Он не даёт журнала порций, лимита стоимости и песочницы файлов.

## Decision

Смысловое извлечение делает внешний агент kbshff, профиль `typical-examples`. Python только нарезает процедуры, ведёт общий журнал по всем `local_configs` и проверяет, что `code` — цитата из процедуры.

- Команда `mine-examples --limit N` берёт следующие N процедур со статусом `pending` и останавливается.
- Журнал `data/.sntx_sem_cache/mine_journal.jsonl` помнит `pending` / `done` / `failed` / `removed` отдельно для каждой пары метка + модуль + процедура.
- Недоступный каталог не помечает свои строки удалёнными.
- `pattern_key` схлопывается только внутри одной конфигурации.
- `find_examples` сначала сопоставляет запрос с `questions` и `task`. Эмбеддинги вопросов в Lance не строятся.
- Каталог справки `all_chunks.jsonl` в порции не читается. Привязка `topic_id` остаётся отдельным проходом (`keyword_link_examples`), не шагом майнера.
- Неизменённый модуль не парсится повторно: кэш `mine_modules.json` хранит размер, mtime и границы процедур. Текст процедуры читается с диска только для текущей порции.
- `examples.jsonl` пишется через временный файл и `replace`. Пока есть `mine_owned`, `scan-examples` этот файл не перезаписывает.

`scan-examples` и `LLMClient` в `linker.py` остаются для механического скана и привязки к статьям справки.

## Consequences

### Positive

- Порцию можно остановить и продолжить. Повтор не спрашивает уже разобранные процедуры, пока не сменился текст.
- Одинаковые относительные пути в разных конфигурациях не смешиваются.
- В базу не попадает код, которого не было в модуле.

### Negative

- Нужны бинарник kbshff и импортированный профиль. Без них команда не стартует и не трогает `examples.jsonl`.
- Лексический поиск по вопросам не ловит далёкий перефраз. Плотный индекс вопросов — отдельное решение, не часть майнера.

### Follow-up

- Если на пилоте живые перефразировки не находятся, рассмотреть отдельный индекс вопросов и новый ADR.
